Why this is the missing layer

Your dashboard already buckets results by season (Fall/Winter/Spring). To be truly multi-year, windows must be year-qualified (F'25 → F'26 → F'27) and sit on one continuous line per student.
That requires the one real lift from the spec: a durable, school-owned student record keyed to a stable code — so Spring of one grade and Fall of the next land on the same line instead of resetting.
Everything else here — items, scoring, tiers, domains, recommendations — is already built. This view is the visualization that lift unlocks.
