ARCHITECTURE OF GRACE — DEPLOY FOLDER
=====================================

This folder is meant to become your LIVE website root. Everything a visitor
needs, nothing they don't. Keep your /src bundle in a SEPARATE folder — never
upload it.

OPTIONAL — TRUE OFFLINE DYSLEXIA FONT (recommended for your audience)
--------------------------------------------------------------------
The dyslexia-friendly toggle uses the OpenDyslexic font. It now loads from a
LOCAL copy if present, and falls back to the CDN if not. To make it work even on
a device that has never been online, make a "fonts" folder here and add two files:

  Make:  fonts/
  Download these two and rename them as shown:
    https://cdn.jsdelivr.net/npm/@fontsource/opendyslexic@5.0.0/files/opendyslexic-latin-400-normal.woff2
        →  fonts/opendyslexic-400.woff2
    https://cdn.jsdelivr.net/npm/@fontsource/opendyslexic@5.0.0/files/opendyslexic-latin-700-normal.woff2
        →  fonts/opendyslexic-700.woff2

  (Open each link in a browser; it downloads the .woff2. Rename to match. Done.)
  Skip this and everything still works — the font just streams from the CDN
  instead, which needs one online visit first.

NEXT TIME YOU MAKE A CHANGE
---------------------------
Edit a module in your /src folder, run "python3 build.py", then upload the NEW
dist/index.html AND dist/sw.js. The build stamps a fresh version into both, so
returning visitors automatically get the update — nothing to remember.
