A class period, start to finish

How it runs

1
Put the link on the board.Tap “Show on the board” above — or the same button inside any activity's teacher panel. The address fills the screen.
2
Students type it and work.Ten problems, hints on demand, feedback that names the error. English and Spanish, one button apart. A student who was absent can open the same link at home.
3
Walk the rows and read the probe.“For the teacher” at the bottom of each student's screen shows independent vs. supported, hints used, and which half of the skill slipped. Copy the row or write it down — nothing travels on its own.
4
No devices? Print it.Every activity prints as a clean worksheet of the same ten problems — and the page itself still works with JavaScript off or the network down. Sets 2 and 3 are the same skills with new numbers, for re-probing weeks later.
