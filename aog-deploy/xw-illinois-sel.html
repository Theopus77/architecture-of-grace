One clarification

One clarification a district should have.The Goal Builder writes social-emotional goals, aligned to these standards. Reading, mathematics, writing, functional and transition goals are written and monitored in IEP Progress, which is a different tool with a different job and carries no SEL standard tag. A district reading only the first line of an older version of this sheet could conclude every goal this framework writes is an Illinois SEL goal. It is not.

Where the standard is actually met

Where the standard is actually met.Every row above is answered first by something a student holds — a book, a chart, a card, a worksheet, a practice page — and second by something a teacher can show. That order is deliberate. A standards crosswalk that leads with a dashboard is describing a screener with lessons attached, and that is not what this is.
