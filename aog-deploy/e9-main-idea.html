Main Idea and Details

You can read the words now. This room is about what a whole paragraph is saying. The topic is what it is about — one or two words, like bears. The main idea is what the paragraph SAYS about the topic, and it takes a sentence, because it can be true or false. Everything else is a detail holding it up. Learn to tell those three apart and you can summarize anything, and spot the sentence that does not belong. One sentence is holding up all the others

Four sentences. Before you ask what they say, ask what they are all ABOUT. One word keeps coming back — bears, they, their, they.

The topic is what a paragraph is about — a word or two, and it cannot be true or false. The main idea is what the paragraph SAYS about that topic, and it takes a whole sentence, because it CAN be true or false. Everything else is a detail holding it up. Find the topic, write the claim, then check that every other sentence supports it.

Two things people get wrong

⚠️ People often think…

The main idea is the first sentence, so I will just copy that one down.

It often is — because putting the point up front is polite to the reader. But a writer building an argument saves it for the end, after so or that is why, and some paragraphs never state it at all and you have to build it yourself. Position is a two-second first guess, not an answer.

Guess from position. Then test the guess against every sentence.

⚠️ People often think…

This answer is true, so it must be the main idea.

The wrong answers are usually true as well. “Bears eat a lot in autumn” is true and covers one detail — too narrow. “Animals are interesting” is true and covers the whole world — too broad. You are not checking whether it is true. You are checking whether it is the size of this paragraph.

One detail left hanging means too narrow. Room left over means too broad.

Topic, claim, check

1 Watch one

A paragraph gives three facts about recycling and never states an idea. Build the main idea.

  1. Find the topic first: recycling keeps coming back, so the topic is recycling.
  2. List what the details actually say: it saves landfill space, it saves energy, it saves the town money.
  3. Ask what all three have in common — they are all ways recycling helps. Write it as a sentence: “Recycling helps a town in more ways than one.”
  4. Check it against all three. Each one is a way it helps, so none is left hanging. It fits.

Helpful Hints

🧭 The unit in one line

Ask what the paragraph is about — that is the topic → then ask what it SAYS about that topic — that is the main idea, and it needs a whole sentence → everything else is a detail holding it up.

Topic = a word. Main idea = a sentence. Details = the legs.

🔑 The one idea

A topic cannot be true or false. “Bears” is not true and it is not false — it is just a subject. “Bears get ready for winter in three ways” CAN be true or false, and that is exactly what makes it a main idea.

⚠️ Traps to avoid

  • The main idea is not always the first sentence. It is often first, sometimes last, and sometimes it is never written down at all — then you build it yourself.
  • A one-word answer is a topic, not a main idea. If your answer has no verb in it, you have not finished.
  • The biggest, most interesting detail is still a detail. Ask whether the paragraph is ABOUT it or whether it is only an example.
  • A main idea that only covers half the details is too narrow. It has to hold up all of them, or nearly all.

📐 The three — the chart

It is a…How longExample
